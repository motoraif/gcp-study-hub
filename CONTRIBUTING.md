# Contributing to GCP Study Hub

Thanks for helping make this the best free Google Cloud study resource! 🎉

## Ways to Contribute

- 🐛 **Fix bugs** - broken links, typos, rendering issues
- 📚 **Add content** - new topics, clearer explanations, diagrams
- 🧩 **Add practice questions** - the question bank always needs more
- 🔗 **Add resources** - great courses, labs, or tools
- 💡 **Share exam tips** - what helped you pass

## How It Works

All pages are generated by `build.py`. **Do not edit the generated HTML directly** - edit `build.py` (or the relevant data file), then re-run the build.

```bash
python3 build.py
python3 -m http.server 8080   # preview at http://localhost:8080
```

## Adding Practice Questions

Edit `data/quiz-questions.json`. Each question looks like:

```json
{
  "id": "pca-010",
  "cert": "PCA",
  "domain": "Designing for security and compliance",
  "question": "Clear, scenario-based question text?",
  "options": ["Option A", "Option B", "Option C", "Option D"],
  "answer": 2,
  "explanation": "Why the correct answer is right (and others wrong)."
}
```

- `cert` must be one of: `CDL`, `ACE`, `ADP`, `GWA`, `PCA`, `PCD`, `PCDOE`, `PCSE`, `PCNE`, `PCDE`, `PDE`, `PMLE`.
- `answer` is the zero-based index into `options`.
- Keep questions original and scenario-based; do not copy from real exams (that violates Google's exam terms).

## Pull Request Checklist

- [ ] Ran `python3 build.py` and committed the regenerated HTML
- [ ] Verified pages render locally
- [ ] Content is accurate and links back to official Google Cloud docs where possible
- [ ] No copyrighted or real-exam material

## Code of Conduct

Be kind and constructive. This is a learning community.
