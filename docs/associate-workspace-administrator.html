Users, Groups & Organizational Units

  • Organizational Units (OUs) - apply settings/policies hierarchically.
  • Groups - for mailing lists and access control.
  • Provisioning via Admin console, GCDS (directory sync), or the Admin SDK / API.
  • SSO and SAML; integration with Cloud Identity.

Services

Configure Gmail (routing, compliance), Drive (sharing policies), Calendar, Meet, and Chat. Control service availability per OU.

Security

  • 2-Step Verification and security keys enforcement.
  • Context-Aware Access and access levels.
  • DLP for Drive and Gmail; data regions; retention with Google Vault.
  • Alert Center and the security investigation tool.

Monitoring, Reporting & Troubleshooting

Use audit logs, reports, and the security dashboard. Troubleshoot mail delivery (headers, SPF/DKIM/DMARC) and access issues.
