🌐 Virtual Private Cloud (VPC)

Global, software-defined networking for your Google Cloud resources.

What it is

A global, software-defined virtual network. Subnets are regional and span all zones in their region. One VPC can hold resources across every region without needing per-region networks.

Core components

  • Subnets (regional IP ranges; auto or custom mode).
  • Firewall rules - stateful; implied deny ingress, allow egress; target by tags or service accounts.
  • Routes and Cloud Router (BGP) for dynamic routing.
  • Cloud NAT for egress from private instances.

Connectivity

Shared VPC shares one network across projects (host + service projects). VPC Peering connects two VPCs privately (non-transitive). Private Service Connect and VPC Service Controls add private access and data-exfiltration perimeters.

🎯 Exam Tips

💡 Remember
  • VPC is global; subnets are regional - a common exam distinction.
  • Firewall rules are stateful; return traffic is automatically allowed.
  • Shared VPC centralizes networking; VPC Peering is non-transitive.
  • Use Cloud NAT so private VMs reach the internet without public IPs.
