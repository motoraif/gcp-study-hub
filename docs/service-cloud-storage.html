What it is

Durable, highly available object storage. Buckets hold objects; names are globally unique. Location types: region, dual-region, multi-region.

Lifecycle & security

  • Lifecycle rules auto-transition or delete objects by age.
  • Uniform bucket-level access (IAM) vs fine-grained ACLs.
  • Signed URLs for time-limited, keyless access.
  • CMEK with Cloud KMS; object versioning; retention policies.

🎯 Exam Tips

💡 Remember
  • All classes have the same availability SLA tier but differ in min storage duration and retrieval cost.
  • Prefer uniform bucket-level access over ACLs for simpler IAM.
  • Signed URLs grant temporary access without IAM changes.
  • Lifecycle rules are the standard answer for cost optimization on cold data.
