Filesystem & Navigation

CommandDoes
pwdPrint working directory
ls -laList all files with details
cd /pathChange directory
cp / mv / rmCopy / move / remove
find / grepSearch files / text
cat / less / tail -fView / page / follow a file

Key directories: /etc (config), /var/log (logs), /home (users), /tmp (temp), /usr/bin (programs).

Permissions

Files have owner/group/other permissions: read (4), write (2), execute (1).

chmod 644 file.txt   # rw-r--r--
chmod 755 script.sh  # rwxr-xr-x
chown user:group f   # change ownership
sudo command         # run as root

Processes & Services

ps aux | grep nginx    # find a process
top / htop             # live resource usage
kill -9 PID            # force-kill
systemctl status sshd  # service status
journalctl -u sshd     # service logs

Networking

ip a                 # interfaces/addresses
ss -tulpn            # listening ports
curl -I https://x    # HTTP headers
ping / traceroute    # connectivity
ssh user@host        # remote shell
💡 On GCP

Connect to Compute Engine VMs with gcloud compute ssh VM_NAME, which handles keys for you.

Shell Scripting

#!/bin/bash
set -euo pipefail
for f in *.log; do
  echo "Processing $f"
  gzip "$f"
done

📋 Study Checklist

Progress0%
  • Navigate the filesystem and use ls, cd, cp, mv, rm
  • Search with find and grep
  • Read logs with cat, less, and tail -f
  • Understand chmod numeric permissions (644, 755)
  • Change ownership with chown and use sudo
  • Inspect processes with ps, top, and kill
  • Manage services with systemctl and journalctl
  • Check networking with ip, ss, curl, and ping
  • SSH to a host and to a GCE VM with gcloud
  • Write a basic bash script with a loop
