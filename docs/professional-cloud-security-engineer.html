Identity & Access

  • Cloud Identity, SSO/SAML, 2SV, and super-admin protection.
  • Least-privilege IAM; conditions; Workload Identity Federation (no SA keys).
  • Organization policies and the policy hierarchy.

Network Security

  • Firewall rules/policies, hierarchical firewall policies.
  • VPC Service Controls perimeters to stop exfiltration.
  • Cloud Armor (WAF, DDoS), Identity-Aware Proxy (IAP), Private Google Access.

Data Protection

  • Default encryption at rest/in transit; CMEK/CSEK with Cloud KMS; Cloud HSM / External Key Manager.
  • Sensitive Data Protection (DLP) for discovery, de-identification, tokenization.
  • Secret Manager; Confidential Computing.

Security Operations

Security Command Center (posture, findings), audit logs, log sinks to BigQuery/SIEM, and Chronicle. Map controls to compliance frameworks (PCI DSS, HIPAA, ISO).
