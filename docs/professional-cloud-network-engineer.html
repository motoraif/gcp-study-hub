VPC Design

  • VPC is global; subnets are regional. Auto vs custom mode.
  • Shared VPC (host/service projects) vs VPC Peering (non-transitive).
  • Routes, firewall rules/policies, network tags, and service accounts.
  • IP addressing: primary/secondary ranges (alias IPs for GKE), RFC 1918 planning.

Load Balancing

TypeScopeUse
Global external Application LBGlobal, L7HTTP(S), CDN, global web apps
Global external proxy Network LBGlobal, L4TCP/SSL proxy
Regional external Network LBRegional, L4Pass-through TCP/UDP
Internal Application/Network LBRegionalInternal services

Hybrid Connectivity

  • Cloud VPN (HA VPN, 99.99%) over the internet.
  • Dedicated Interconnect (10/100 Gbps) and Partner Interconnect.
  • Cloud Router for dynamic (BGP) route exchange.
  • Network Connectivity Center for hub-and-spoke topologies.

Network Services

Cloud DNS (public/private zones, DNS peering), Cloud NAT, Cloud CDN, Cloud Armor, Private Service Connect, and VPC Flow Logs / Network Intelligence Center for troubleshooting.
