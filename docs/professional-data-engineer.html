Pipelines

  • Pub/Sub - ingest streams; ordering keys, dead-letter topics, exactly-once.
  • Dataflow - Apache Beam, unified batch/stream, windowing, watermarks.
  • Dataproc - managed Spark/Hadoop; ephemeral clusters, autoscaling.
  • Data Fusion - visual ETL; Datastream - CDC.

BigQuery

  • Partitioning (time/ingestion/integer) and clustering for cost/performance.
  • On-demand vs capacity (slots/editions) pricing; reservations.
  • Materialized views, authorized views, and row/column-level security.
  • Streaming inserts vs the Storage Write API; external/BigLake tables.

ML & Analytics

BigQuery ML for SQL-based models; Vertex AI for custom training/serving. Know feature engineering, batch vs online prediction, and when to use pretrained APIs.

Orchestration & Governance

Cloud Composer (managed Airflow) and Dataflow templates for automation. Dataplex for governance, Data Catalog for metadata, and DLP for sensitive data.
