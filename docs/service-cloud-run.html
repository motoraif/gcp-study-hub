🚀 Cloud Run

Serverless containers that scale to zero and pay per request.

What it is

A fully managed platform to run stateless containers. It scales automatically (including to zero), and you pay only while requests are being served.

Scaling & config

  • Concurrency - requests served per container instance.
  • Min instances reduce cold starts; max instances cap scale.
  • Request timeout and CPU allocation are configurable.

Deploy & integrate

Traffic splitting across revisions enables canary and blue/green releases. Integrates with Pub/Sub (push), Secret Manager, Cloud SQL, and sits behind the global load balancer with Cloud CDN.

🎯 Exam Tips

💡 Remember
  • Scales to zero - cost-efficient for spiky or low-traffic services.
  • Tune concurrency and min instances to balance cost vs cold starts.
  • Traffic splitting across revisions gives canary deployments.
  • Use it for stateless HTTP/event-driven workloads, not stateful apps.
