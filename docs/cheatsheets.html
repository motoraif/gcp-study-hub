Quick Reference

📝 Confusing Pairs Cheat Sheet

The look-alike Google Cloud services that trip people up on exams, compared side by side. Memorize the right-hand distinctions.

Cloud SQL vs Spanner

Cloud SQLSpanner
Regional managed MySQL/PostgreSQL/SQL ServerGlobally distributed relational
Vertical scaling, read replicasHorizontal scaling, 99.999% multi-region
Lift-and-shift OLTPGlobal scale + strong consistency

Bigtable vs BigQuery

BigtableBigQuery
Wide-column NoSQL (operational)Analytics data warehouse (OLAP)
Low-latency, high-throughput reads/writesServerless SQL over huge datasets
Time-series, IoT, fraud detectionReporting, BI, ad-hoc analytics

Pub/Sub vs Cloud Tasks

Pub/SubCloud Tasks
Many-to-many event streamingExplicit task dispatch to a worker
Fan-out, decoupling, analytics ingestionRate-limited, scheduled task execution
At-least-once (and exactly-once option)Per-task control and deduplication

Dataflow vs Dataproc

DataflowDataproc
Serverless Apache Beam (batch + stream)Managed Spark/Hadoop clusters
No cluster to manage, autoscalingLift-and-shift existing Spark/Hadoop
Unified pipelinesEphemeral clusters for jobs

Firewall Rules vs Hierarchical Firewall Policies

Firewall RulesHierarchical Firewall Policies
Applied at the VPC levelApplied at org/folder level, inherited
Target by tags or service accountsEnforce org-wide guardrails
Project-scopedCentralized governance

Cloud Run vs GKE

Cloud RunGKE
Serverless containers, scale-to-zeroFull Kubernetes control
Simple stateless servicesComplex microservices, operators, DaemonSets
Pay per requestPay for nodes (Standard) or pods (Autopilot)

Basic Roles vs Predefined/Custom Roles

Basic RolesPredefined/Custom Roles
Owner/Editor/Viewer, broadGranular per-service permissions
Convenient but over-privilegedLeast-privilege, recommended for prod
Avoid in productionPreferred everywhere

Committed Use Discounts vs Spot VMs

Committed Use DiscountsSpot VMs
Commit 1 or 3 years for steady workloadsUp to ~91% off spare capacity
Guaranteed capacity + discountCan be preempted with ~30s notice
Predictable baselineFault-tolerant batch only
