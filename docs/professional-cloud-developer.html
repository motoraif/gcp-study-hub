Compute Targets

Pick the right runtime: Cloud Run (stateless containers, scale-to-zero), GKE (complex microservices), App Engine (PaaS), Cloud Functions (event glue). Know cold starts, concurrency, min instances, and request timeouts.

Data & Caching

  • Firestore for app data; understand transactions and indexes.
  • Cloud SQL / Spanner for relational.
  • Memorystore (Redis/Memcached) for caching.
  • Cloud Storage for assets; signed URLs for direct access.

APIs & Messaging

Design REST/gRPC APIs; use API Gateway/Apigee. Decouple with Pub/Sub (at-least-once, ordering keys, dead-letter topics) and Cloud Tasks (rate-limited task queues).

Build & Deploy

  • Cloud Build for CI; store images in Artifact Registry.
  • Deployment strategies: rolling, blue/green, canary (traffic splitting on Cloud Run / GKE).
  • Manage config/secrets with Secret Manager and env vars.

Observability

Instrument with Cloud Logging, Cloud Trace, Cloud Profiler, and Error Reporting. Use structured logs and correlation IDs.
