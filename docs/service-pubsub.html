📣 Pub/Sub

Global, scalable messaging for event-driven and streaming systems.

What it is Delivery & subscriptions Patterns Exam Tips

What it is

A fully managed, global messaging service. Publishers send messages to topics; subscribers receive them via subscriptions. Decouples producers from consumers.

Delivery & subscriptions

  • Pull vs Push subscriptions.
  • At-least-once delivery by default; exactly-once available.
  • Ordering keys preserve order per key.
  • Dead-letter topics capture messages that repeatedly fail.

Patterns

Fan-out (one topic, many subscriptions), stream ingestion into Dataflow/BigQuery, and decoupling microservices. Acknowledge within the ack deadline or messages redeliver.

🎯 Exam Tips

💡 Remember
  • Default delivery is at-least-once; design idempotent consumers.
  • Use ordering keys when per-key order matters (same region).
  • Dead-letter topics prevent poison messages from blocking a subscription.
  • Pub/Sub is the standard entry point for streaming pipelines into Dataflow/BigQuery.
