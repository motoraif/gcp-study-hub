Transformation

  • Dataflow - unified batch + stream (Apache Beam).
  • Dataproc - managed Spark/Hadoop for lift-and-shift big data.
  • Dataprep / Cloud Data Fusion - visual, low-code ETL.
  • BigQuery SQL + scheduled queries - in-warehouse ELT.

Analysis & BI

  • BigQuery - serverless SQL analytics; partitioning & clustering for cost/perf.
  • Looker / Looker Studio - dashboards and self-serve BI.
  • BigQuery ML - train models with SQL.

Governance

Understand Dataplex (data governance/catalog), IAM for datasets, column/row-level security in BigQuery, and data retention/lifecycle policies.

📋 Study Checklist

Progress0%
  • Choose ingestion services (Pub/Sub, Cloud Storage, transfer services)
  • Select the right storage/warehouse for a data workload
  • Build transformations with Dataflow, Dataproc, and Data Fusion
  • Write efficient BigQuery SQL; use partitioning and clustering
  • Create dashboards with Looker Studio
  • Train models with BigQuery ML at a basic level
  • Apply dataset IAM and column/row-level security
  • Use Dataplex for cataloging and governance
  • Orchestrate pipelines (Cloud Composer / scheduled queries)
  • Manage data lifecycle, retention, and cost
