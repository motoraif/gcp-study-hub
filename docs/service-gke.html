What it is

Managed Kubernetes. Google runs the control plane. Autopilot manages nodes for you (pay per pod); Standard gives node control.

Key concepts

  • Clusters, node pools, pods, services, deployments.
  • Regional clusters for HA control plane.
  • Cluster autoscaler + horizontal pod autoscaler.

Security & networking

  • Workload Identity maps K8s SAs to Google SAs (no keys).
  • Binary Authorization enforces trusted images.
  • VPC-native (alias IP) clusters; private clusters.

🎯 Exam Tips

💡 Remember
  • Autopilot = less ops, pay-per-pod; Standard = node control.
  • Use Workload Identity instead of exporting service account keys.
  • Regional clusters give a highly available control plane.
  • VPC-native clusters use alias IP ranges for pods/services.
