📊 BigQuery

Serverless, highly scalable data warehouse with built-in ML.

What it is Performance Pricing Security Exam Tips

What it is

Serverless analytics warehouse. Separates storage from compute. Standard SQL. Scales to petabytes with no infrastructure to manage.

Performance

  • Partitioning (by time/ingestion/integer) prunes scanned data.
  • Clustering sorts data within partitions for faster filters.
  • Materialized views precompute results.

Pricing

  • Storage - active vs long-term (auto-discounted).
  • Compute - on-demand (per TB scanned) or capacity (slots/editions).

Security

Dataset-level IAM, authorized views, row-level and column-level security, and VPC Service Controls.

🎯 Exam Tips

💡 Remember
  • Partition + cluster large tables to cut on-demand query cost.
  • On-demand is priced per TB scanned - SELECT only needed columns.
  • Use authorized views to share results without exposing source tables.
  • BigQuery is OLAP (analytics), not OLTP - don't use it for transactional apps.
