SRE Principles

  • SLI / SLO / SLA and error budgets drive release decisions.
  • Toil reduction through automation.
  • Blameless postmortems and a culture of learning.

CI/CD Pipelines

Cloud Build (triggers, build config), Artifact Registry, Cloud Deploy (managed progressive delivery to GKE/Cloud Run), and GitOps patterns. Infrastructure as code with Terraform and Config Controller.

Monitoring

Google Cloud Observability: Cloud Monitoring (metrics, dashboards, SLO monitoring, alerting), Cloud Logging (log-based metrics, sinks), Cloud Trace/Profiler. Define alerting policies tied to SLOs, not raw symptoms.

Incident Management

On-call, incident response roles, escalation, and postmortems. Use error budget burn-rate alerts to catch fast and slow failures.
