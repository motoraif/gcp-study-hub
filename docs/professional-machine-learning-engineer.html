Vertex AI

The unified ML platform: AutoML (low-code), custom training, Model Registry, Endpoints, Pipelines, Feature Store, and the Model Garden / Gemini for generative AI. Know when to use AutoML vs custom vs pretrained APIs.

Data & Features

  • Feature engineering; Vertex AI Feature Store for reuse/consistency.
  • Data in BigQuery / Cloud Storage; TFRecord, managed datasets.
  • Handle imbalance, leakage, and train/serve skew.

Training & Tuning

  • Custom training with containers; distributed training; GPUs/TPUs.
  • Hyperparameter tuning (Vertex AI Vizier).
  • Transfer learning and foundation-model fine-tuning.

Serving

Online (low-latency endpoints, autoscaling) vs batch prediction. Optimize cost/latency; use private endpoints; model versioning and traffic splitting.

MLOps

Vertex AI Pipelines (Kubeflow/TFX) for automation, Model Monitoring for drift/skew, CI/CD for models, and the Model Registry for governance and lineage.
