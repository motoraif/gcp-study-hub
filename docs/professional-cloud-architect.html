Security & Compliance

  • Least privilege with predefined/custom IAM roles; avoid basic roles in production.
  • Org policies to enforce guardrails (e.g., restrict resource locations, disable SA key creation).
  • VPC Service Controls to prevent data exfiltration from managed services.
  • CMEK/CSEK with Cloud KMS for customer-managed encryption keys.
  • Security Command Center for posture, vulnerabilities, and threat detection.
  • Shielded VMs, Binary Authorization (GKE), and Workload Identity.

Reliability & SRE

SRE concepts

  • SLI - a measured indicator (e.g. latency, error rate)
  • SLO - target for an SLI (e.g. 99.9%)
  • SLA - contractual promise with consequences
  • Error budget - allowed unreliability (1 - SLO)

HA/DR patterns

  • Multi-zone and multi-region deployments
  • RPO (data loss tolerance) vs RTO (recovery time)
  • Backup/restore, warm standby, hot (active-active)
  • Health checks + autohealing + autoscaling

Migration

Know the "5 Rs": Rehost (lift-and-shift with Migrate to Virtual Machines), Replatform, Refactor, Repurchase, and Retire. For data: Storage Transfer Service (online), Transfer Appliance (offline, large), Database Migration Service (DBs), and BigQuery Data Transfer Service.

Cost Optimization

  • Committed use discounts (1 or 3 year) for steady workloads.
  • Spot VMs for fault-tolerant batch.
  • Sustained use discounts applied automatically on Compute Engine.
  • Right-size with recommendations (Active Assist / Recommender).
  • Cloud Storage lifecycle policies to move cold data to cheaper classes.
  • BigQuery: partitioning, clustering, and slot reservations.
