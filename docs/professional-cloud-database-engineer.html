SpannerRelational, globally distributedGlobal scale, strong consistency, 99.999%

FirestoreDocument NoSQLMobile/web apps, serverless
MemorystoreIn-memory (Redis/Memcached)Caching, sessions
BigQueryAnalytics warehouseOLAP, not OLTP

HA & Scaling

Cloud SQL regional HA (failover replica), read replicas (incl. cross-region), and maintenance windows. Spanner nodes/processing units and multi-region configs. Bigtable replication and cluster routing.

Migration

Database Migration Service (DMS) for homogeneous/heterogeneous migrations with minimal downtime. Understand continuous replication, cutover, and Datastream for CDC.

Security

IAM database roles, CMEK, private IP + Private Service Connect, Cloud SQL Auth Proxy, and audit logging.
