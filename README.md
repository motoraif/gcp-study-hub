## What's Inside

- 🐧 **Linux Fundamentals** - file system, permissions, scripting, SSH
- 🌐 **Networking Fundamentals** - OSI model, CIDR, DNS, VPC concepts
- ☁️ **12 Google Cloud Certifications** - Cloud Digital Leader, Associate Cloud Engineer, Associate Data Practitioner, Workspace Administrator, and the 8 Professional tracks (Architect, Developer, DevOps, Security, Network, Database, Data Engineer, ML Engineer)
- 🔬 **Service Deep Dives** - Compute Engine, GKE, Cloud Storage, BigQuery, IAM
- 🧩 **Interactive Study Tools** - practice quiz, SM-2 flashcards, cheat sheets, progress dashboard, instant site search
- 🔗 **Resources & Labs** - Skills Boost, Coursera, free tier, hands-on project ideas
- 🔄 **Auto-Updated** - GitHub Actions pulls Google Cloud release notes weekly

## Quick Start (Local)

```bash
git clone https://github.com/motoraif/gcp-study-hub.git
cd gcp-study-hub
python3 build.py        # regenerate all HTML, search index, and sitemap
python3 -m http.server 8080
# Open http://localhost:8080
```

The entire site is generated by `build.py` into `index.html` and `docs/`. Edit content in `build.py`, re-run it, and commit the generated HTML.

## Project Structure

```
build.py                 # static-site generator (edit content here)
index.html, docs/*.html  # generated pages (do not hand-edit)
assets/css/style.css     # Google-themed styles
assets/js/*.js           # components (nav/footer), search, quiz, flashcards, dashboard, main
data/quiz-questions.json # practice question bank (contributions welcome)
data/gcp-news.json       # auto-updated Google Cloud news archive
data/search-index.json   # generated by build.py
.github/workflows/       # deploy + weekly news update
```
